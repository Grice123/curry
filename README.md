# 李巴乔 · 个人主页

用于个人介绍和求职的静态网页，支持中文、英文切换及手机浏览。没有构建步骤或外部依赖，下载 `index.html` 后直接用浏览器打开即可。

## 本地运行

在此目录运行：

```sh
python3 -m http.server 8000
```

在运行该命令的电脑上访问 `http://localhost:8000`。云端运行时，这个地址仅用于内部检查。

## 内容与交互

内容基于提供的简历；硕士专业按本人确认统一为计算机科学。仅展示获准公开的邮箱，不含手机号，也不提供包含手机号的原始简历下载。

页面正文集中在 `index.html` 中，`data-zh` 和 `data-en` 对应两种语言。切换时更新正文、页面标题和描述，并在浏览器允许时记住语言。联系按钮使用 `mailto:`，调用用户已配置的邮件应用；网页本身不发送邮件，也不收集表单信息。

数值为简历记录的累计成果。职位、日期、项目及荣誉可在履历更新时手动修改。
